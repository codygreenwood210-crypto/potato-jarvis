## Durable commercial lessons

### Protect canonical IP

Before converting a game's production library into a marketplace pack, classify assets as `CANONICAL/EXCLUSIVE`, `GENERIC/RESELLABLE`, `THIRD-PARTY/REVIEW`, or `REJECT`. Distinctive heroes, story art, portraits, project branding and other identity-bearing material should remain exclusive unless the user explicitly decides otherwise.

### Truth-in-listing from the release artifact

Marketplace counts, screenshots and claims must be derived from the final auditable release package, not from aspiration, AI-generated marketing text, or raw file counts. Hash/deduplicate assets, calculate unique counts, generate previews from actual included files, and reject any numerical/visual claim that cannot be traced back to the release artifact.

### Revenue is a separate evidence gate

A polished ZIP is not revenue. A live listing is not revenue. A sale is not necessarily profit. Track the evidence ladder accurately and do not celebrate vanity metrics while ignoring fees/costs.
