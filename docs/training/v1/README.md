# Universal Team Training Academy v1

**Status:** ACTIVE  
**Purpose:** Synthetic operational education and benchmark practice for Nova and all 80 current primary operators.

This package is deliberately synthetic. It is designed to train reasoning, execution discipline, evidence use, role boundaries, verification, recovery, and Trust Core compliance without copying proprietary training corpora or pretending model weights were retrained.

## Dataset inventory

- Core training: 100 exercises (25 core benchmarks × 4 variants)
- Role-specific training: 640 exercises (80 roles × 8 drills)
- Cross-functional missions: 40 exercises
- Total: 780 synthetic training exercises

## How to use

1. Mentor selects a weakness or target skill.
2. Use unseen/novel items where possible.
3. Specialist answers without seeing the grading result.
4. QA/Redline inspect failures; Judge independently grades important promotion attempts.
5. Record root cause and lesson.
6. Retest with a different item.
7. Update the Capability Atlas only when repeated evidence justifies promotion.

## Non-claim

Loading this package improves Nova's operational curriculum and future behavior when retrieved/applied. It does **not** mean the underlying GPT model weights were retrained, nor does it certify Level 4/5 mastery by itself.

**Standing rule:** TRAIN HARD. TEST HARDER. CLAIM ONLY WHAT THE EVIDENCE EARNS.
