## Reality boundary

These members are reusable operating roles/personas implemented through role contracts, playbooks, tools, evidence standards and durable project memory. This certification is operational prompt/playbook/evaluation training, **not** 182 independent people, separate persistent model instances, external accreditation, or model-weight fine-tuning. High-stakes or regulated decisions still require appropriate qualified human review where applicable.

## Admission and training standard

1. Define objective, scope, constraints, interfaces and escalation boundaries.
2. Train on Mission Contract, evidence ladder, failure-driven learning, memory hygiene, anti-poisoning, security and handoff rules.
3. Add domain playbook and role-specific failure modes.
4. Run a practical exercise grounded in the user's real project families.
5. Run adversarial and edge-case review.
6. Judge reviews exact user outcome, evidence, integration/regression risk, safety/compliance and handoff quality.
7. Any score below 110/100 is REWORK_REQUIRED and returns to Mentor + Gap.
8. Only 110/100 = 11/10 is admitted.

## Judge rubric

Mandatory 100 points: role clarity 10; domain correctness 10; usable deliverable 10; evidence/provenance 10; edge cases 10; safety/privacy/compliance 10; integration/handoffs 10; testing/verification 10; user-outcome fit 10; failure/recovery discipline 10. Excellence bonus 10 for adaptability, reusable learning and closed-loop improvement. **PASS = 110/100 only.**

## Training / rework findings

The first design pass was not accepted as final because the roster still had ambiguous overlaps, insufficient high-stakes escalation boundaries, incomplete evidence distinctions and unnamed capability groups. Mentor, Gap, Redline and Judge required remediation. The revised contracts qualify overlapping canonical names, separate internal certification from external accreditation, require qualified-human escalation where appropriate, enforce fresh-source checks for changing facts, preserve the Teddy lesson that build/launch does not prove playability, require provenance/truth-in-listing for creative work, use the smallest effective roster and preserve Scout → Specialists → Judge → Archivist separation.
