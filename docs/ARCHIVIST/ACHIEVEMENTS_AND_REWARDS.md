# POTATO Archivist — Achievements, Recognition & Rewards Ledger

This file preserves team accomplishments and any real rewards across chats. It must remain evidence-based.

## Rules

- `Achievement` = a supported technical/project milestone.
- `Recognition` = praise, rating, award or acknowledgement actually given by the user, Judge or an external system/source.
- `Reward` = a concrete benefit/prize/payment/perk actually granted. Never infer one.
- Every entry must identify its type and provenance.
- No monetary or external reward is recorded unless it actually happened and there is a safe record of it.

## Record format

Each entry should include: `ID`, `Date`, `Type`, `Recipient(s)`, `Title`, `Reason`, `Evidence`, and `Notes`.
