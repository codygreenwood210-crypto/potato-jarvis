## Interpretation rule

The four user-supplied polished boards and the polished Moonstitch/storyboard visuals define the intended **commercial quality direction**: detailed, cohesive, high-quality Gothic Halloween pixel art with rich purple/gold/orange lighting, warm architectural windows, readable silhouettes, coherent palettes and game-ready presentation.

The current v1.1 comparison previews are evidence of the existing pack state, **not the final quality target**. They should be used to identify replacement/upgrade work.

## Canon visual constraints

- Teddy is one person.
- Golden Heartland and violet Nightmare magic are both part of Teddy.
- Nightmare magic is not evil.
- Do not create/use a separate evil Shadow Teddy in the main story.
- Teddy's directional sprites must preserve which anatomical side is golden and which is purple; naive mirroring is not acceptable if it swaps canonical sides.
- Combined gold/violet magic is a signature visual system.

## Binary-image storage note

The GitHub connector available during this closeout can create/update UTF-8 text files but does not expose a binary-image commit action. Therefore the images themselves were embedded and verified in the Google Doc, and GitHub stores this durable index/pointer. Do not later claim the PNG binaries were committed to GitHub unless a binary-capable GitHub workflow actually does so.
